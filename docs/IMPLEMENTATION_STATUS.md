## OpenAI 호환 연결 근거

기존 Responses 기본 동작을 유지하면서 사용자 지정 Base URL, Chat Completions,
JSON Schema / JSON 모드 / 프롬프트 JSON 선택을 추가했습니다. 새 출력 방식도 동일한
로컬 검증을 거칩니다. 잘림·거절·도구 호출·비 JSON 응답은 실패로 처리하며 자동 재시도하지
않습니다. 변환 단계만 완성된 JSON의 출력 계약 위반을 최대 1회 교정합니다.
대상 호스트 변경 시 기존 키의 무의식적 재사용을 막습니다. 외부 HTTP 주소,
userinfo·쿼리·전체 endpoint 주소를 차단하고 실제 endpoint를 화면에 표시합니다.

실제 계정·키로 과금 호출은 실행하지 않았습니다. 테스트에는 가짜 키와 모의
응답만 사용했습니다. 실제 모델의 지원 형식과 창작 품질은 별도로 확인해야 합니다.

## 웹 API 설정 추가

상단 API 설정 모달과 `/api/settings`를 추가했습니다. 저장값은 Git에서 제외된
`.local-secrets/ui-settings.json`에 원자적으로 기록하며 기존 `.env`는 변경하지 않습니다.
환경변수 항목은 UI와 서버 양쪽에서 변경을 차단합니다. 키 값은 GET 설정 응답에 포함하지
않고 설정창을 닫을 때 키 입력란을 비웁니다. 로컬 파일의 API 키는 암호화하지 않습니다.

단위 테스트에는 키 값 미노출, 환경변수 우선순위, 실패 시 기존 파일 보존, 기존 `.env`
보존, 외부 Origin 설정 변경 차단을 포함합니다. 실제 사용자 키는 읽거나 저장하지 않았습니다.

브라우저 스크린샷은 ignored `storage/browser-check`에 있습니다. 원격 API는 실제로
호출하지 않았고, 테스트용 가짜 키와 모의 응답만 사용했습니다. 실제 API 사용 가능 여부,
페르소나 반영 품질, 비용, 실제 영상의 연결성은 위 결과로 검증되지 않았습니다.
