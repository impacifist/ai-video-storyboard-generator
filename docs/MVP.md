# MVP 요구사항

## 목표

캐릭터 두 명과 상황을 입력하면, 캐릭터의 성격과 사용자의 의도를 유지하며
대사·행동·연출 지시가 포함된 컷별 텍스트 콘티를 생성하고 수정할 수 있게 합니다.

## 입력

- 캐릭터: 고유 ID, 이름, 성격, 말투, 욕구, 두려움, 행동 습관, 고정 설정
- 관계: 상대에 대한 태도, 현재 친밀도, 갈등, 공유하거나 모르는 정보
- 장소·상황: 공간, 시간대, 분위기, 등장인물의 시작 위치, 소품
- 사용자 의도: 원하는 상호작용, 장면 목표, 결말, 필수 요소, 제외 요소
- 제작 조건: 목표 길이, 표현 스타일

입력은 직접 작성과 임포트를 지원하는 방향으로 설계합니다.
구체적인 파일 형식과 이미지 입력 지원은 구현 설계 단계에서 정합니다.
사용자 지정 사실과 AI가 제안한 설정을 구분해 보관합니다.

## 출력

사람이 읽는 콘티 표와 프로그램이 읽는 구조화된 JSON을 같은 원본에서 만듭니다.

각 컷은 다음 정보를 가집니다.

- 컷 ID, 장면 ID, 예상 길이
- 장면 내 역할과 감정 변화
- 등장인물 ID, 화자 ID, 대사, 순서가 있는 행동
- 화면 구도, 샷 크기, 시점, 카메라 움직임, 다음 컷 전환
- 시작·종료 상태: 위치, 자세, 시선, 감정, 소품 상태
- 다음 컷에서 유지해야 할 연속성 조건

대사 낭독 시간과 행동 시간을 고려하며, 예상 길이를 실제 영상 길이로 보장하지 않습니다.

## 편집과 검수

- 사용자가 특정 대사·컷·설정을 고정하고 나머지를 재생성할 수 있습니다.
- 변경된 컷에 영향을 받는 후속 컷을 다시 검수합니다.
- 성격과 말투의 이탈, 사용자 조건 위반, 인물이 모르는 정보의 사용을 점검합니다.
- 위치·소품·시선·행동의 연결과 시간 내 수행 가능성을 점검합니다.
- 형식 오류는 프로그램으로, 이야기와 연출의 적합성은 AI 검수 및 사용자 검토로 확인합니다.
- 검수 결과와 수정 이력을 표시하고, AI 검수만으로 품질을 보장한다고 주장하지 않습니다.

## 완료 기준

1. 캐릭터 두 명과 장소·상황·원하는 결말을 입력할 수 있습니다.
2. 입력과 연결된 컷별 대사·행동·연출 콘티를 생성합니다.
3. 화자와 등장인물 참조, 필수 필드, 시간 값의 형식 검증을 통과합니다.
4. 성격 및 연속성 검수 결과를 확인할 수 있습니다.
5. 일부 컷을 고정하고 다른 컷을 수정·재생성할 수 있습니다.
6. 콘티 표와 JSON으로 내보낼 수 있습니다.

## 후속 범위

- 장소 참조 이미지, 영상·오디오 참조 관리
- 콘티 패널 이미지 생성과 시각적 일관성 검수
- 긴 컷의 의미 기반 자동 분할
- 영상 생성 요청, 결과 검수, 클립 연결
- 음성·음악·효과음 제작 및 편집

## 첫 구현에서 정한 항목

- Python 표준 라이브러리와 HTML/CSS/JavaScript를 이용한 로컬 웹앱
- Ollama, OpenAI, Claude 제공자를 선택하고 모델 ID는 사용자가 지정
- 입력과 프로젝트의 JSON 임포트 및 파일 다운로드 방식 저장
- 대사별 잠금 대신 컷 전체 고정, 콘티 패널 그림 대신 텍스트 콘티 카드
- 비용 한도·실제 제공자 호출 품질·그림 패널은 후속 검증 또는 구현 범위

이 문서는 목표 범위를 정의합니다. 실제 구현 범위와 제한은 README 및 ARCHITECTURE.md를
참조하세요. 의미 검수 의견만으로 작품 품질이나 캐릭터 일관성을 보장하지 않습니다.

## 두 번째 기능의 현재 범위

콘티 보관함과 관리 탭, 변환 탭을 추가했습니다. 저장한 콘티에서 컷을 선택하고 최대
15초 클립 계획을 확인한 뒤 Seedance 2.0/MiniMax H3 공식 프로필 또는 고급 직접 입력
가이드를 기준으로 프롬프트를 만듭니다. 저장 콘티의 원본 내용 확인, 캐릭터별 복수 이미지의
용도·설명·순서 설정과 ZIP 내보내기를 지원합니다. 공식 프로필은 정수 4~15초 길이를
요구합니다. 원본은 보존하며 클립 대응·원문 대사·참조 번호·H3 필수 섹션을 검사합니다.
가이드 전체의 의미적 준수는 검토가 필요합니다. 실제 영상 생성은 후속 범위입니다.
