# v0.5.5-beta

Each converted clip now has a **Copy prompt** button. Copy C01 or C02 directly, even when its details are collapsed. Only the selected clip's prompt body is copied; dialogue and line breaks are preserved. Existing TXT/JSON/ZIP downloads remain available. Clipboard success and failure are shown beside the button, with a selection-based fallback when the Clipboard API is unavailable.

English, Korean and Japanese documentation now uses matching UI screenshots and authored examples. A Japanese storyboard JSON and prompt TXT are included. Screenshots use the actual application with temporary storage and mocked AI responses; they do not demonstrate live model quality.

Validation: 174 unit tests, Ruff and JavaScript syntax passed. All three showcase browser runs checked two separate clip copies against the actual clipboard (accounting for Windows newline conversion), copying a collapsed clip, the fallback copy path, preserved dialogue, English directions and TXT export. No paid AI calls or video generation were run.

Update by stopping the old server, backing up `storage/`, `.local-secrets/` and `.env`, then extracting the new ZIP into a separate folder. Copy your private data into it, start the app and refresh the browser. Keep the old folder until you have verified the update.
