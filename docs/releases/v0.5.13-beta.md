# v0.5.13-beta — Directional clip connections without duplicated action bridges

## English

- Removes free-form `handoffs`, `bridge` and `sound_bridge` fields from the LLM output contract. A shared action sentence is no longer inserted at both the previous clip's end and the next clip's beginning.
- The renderer supplies different outgoing/incoming scope rules. Continuous shots inherit the already-established state and resume only unfinished motion; planned cuts preserve each shot's own action/state and approved transition; scene changes preserve each scene's own context and audio.
- Concrete actions stay in their assigned shot direction, and audio stays in the clip's soundscape/music. Compiler instructions also prevent future behavior from being placed in context, summaries, subject definitions or reference-retention notes. This does not semantically prove that every model response or rendered video follows the plan.
- Assembly version 9 exposes the renderer's `handoff_policy` in request/output inspection downloads. LTX retains prose without internal boundary headings; approved closing transitions remain explicit.

Existing saved prompts, signed STRING snapshots and video workflows are not rewritten. Restart after updating, refresh with Ctrl+F5 and **convert the storyboard again** to use the new policy. In ComfyUI, select the new clips and explicitly update the desired prompt nodes.

Validation: 231 unit tests, Ruff/JavaScript checks and browser conversion/inspection/export regressions. Synthetic cup-raising/sipping cases cover all six H3/Seedance/LTX guide modes, split-motion state inheritance, scene changes, selection gaps, approved cuts and bounded repair of legacy handoff output. AI responses are mocked; actual rendered continuity is not verified. ZIPs exclude private settings, API keys, saved databases and generated media.

## 한국어

이전 클립 끝과 다음 클립 시작에 같은 행동 문장을 넣던 연결 구조를 제거했습니다. 이제 연결부에는 프로그램이 구간별 범위 규칙을 넣고, 실제 행동은 배정된 컷에서만 지시합니다. 연속 동작·컷 전환·장면 전환을 각각 다르게 처리하며, LLM 전송 이력 보기에서 최종적으로 추가된 연결 규칙도 확인할 수 있습니다.

단위 테스트 231개와 브라우저 검증을 통과했습니다. 실제 영상의 반복 동작 해소는 새 생성으로 확인해야 합니다. 업데이트 후 서버 재시작·Ctrl+F5를 하고 **기존 콘티의 프롬프트를 다시 변환**하세요. 저장된 예전 프롬프트는 자동으로 바뀌지 않습니다.

## 日本語

前のクリップ末尾と次のクリップ冒頭に同じ動作文を入れる接続処理を廃止しました。接続部にはプログラムが区間ごとの範囲規則を追加し、具体的な動作は割り当てられたカットだけで指示します。連続動作・カット切り替え・場面転換をそれぞれ区別し、LLM入力・出力の確認画面で実際に追加された接続規則も確認できます。

単体テスト231件とブラウザー検証を通過しました。実際の動画で動作の反復が解消するかは新しい生成で確認が必要です。更新後はサーバー再起動・Ctrl+F5を行い、**既存ストーリーボードのプロンプトを再変換**してください。保存済みの旧プロンプトは自動変更されません。
