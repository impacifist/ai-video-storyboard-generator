# v0.5.4-beta — 모든 지원 로컬 AI 연결의 출력 예산 설정

2026-10-17 · AI Video Storyboard Generator

## 변경

- **API 설정 → Ollama → 요청 출력 한도**를 추가했습니다. 저장한 값을 `options.num_predict`로 전송합니다.
- **API 설정 → OpenAI → 로컬 연결 출력 한도**를 추가했습니다. Base URL의 호스트가 `localhost`, `127.0.0.1`, `::1`인 호환 서버에 적용하며 Chat Completions의 `max_tokens`, Responses의 `max_output_tokens`를 설정합니다. 클라우드 연결의 기존 출력 한도는 유지합니다.
- 기존 **LM Studio → 요청 출력 한도**와 함께 제공자별 값을 따로 저장하고 콘티 제작·검수·변환에 적용합니다. 기본 16000, 범위 256~131072입니다. 진단 로그에도 실제 요청 한도를 표시합니다.
- `.env`와 환경변수의 `OLLAMA_MAX_TOKENS`, `LMSTUDIO_MAX_TOKENS`, `OPENAI_LOCAL_MAX_TOKENS`를 지원합니다. 환경변수로 관리하는 항목은 웹에서 변경할 수 없습니다.
- Ollama가 `length`로 종료하면 출력 잘림과 한도·컨텍스트 확인 방법을 안내합니다.

출력 예산은 모델의 컨텍스트 길이 또는 추론 예산과 다릅니다. 입력과 출력 예산이 로드한 컨텍스트 안에 들어가도록 조절하고, 추론이 길면 모델의 추론 설정도 확인하세요. 한도를 높여도 완성과 품질은 보장되지 않습니다. 고정 소켓 대기 제한 제거, 진단 로그, 기존 검증은 유지하며 자동 재시도나 미완성 결과 저장은 추가하지 않았습니다.

## 업데이트

기존 서버를 종료하고 개인 `storage/`, `.local-secrets/`, 선택 `.env`를 백업하세요. 새 ZIP을 별도 폴더에 풀고 개인 데이터를 복사한 뒤 `start.bat` 또는 `python server.py`로 실행하고 브라우저를 새로고침하세요. Python 3.12 이상이 필요합니다. 기존 콘티와 변환 결과는 재작성하지 않습니다.

ZIP에는 릴리스 커밋의 소스·문서·예제·테스트만 포함합니다. 개인 데이터·키·업로드·진단 결과는 제외하며 `SHA256SUMS.txt`를 제공합니다.

## English

Configurable output budgets now cover all supported local connections: Ollama, LM Studio, and OpenAI-compatible endpoints on `localhost`, `127.0.0.1` or `::1`. Each connection stores its own value (default 16000, range 256–131072) for generation, review and conversion. Ollama uses `options.num_predict`; compatible Chat Completions/Responses use `max_tokens`/`max_output_tokens`. Cloud output limits remain unchanged. Diagnostics show the actual requested limit.

Environment settings: `OLLAMA_MAX_TOKENS`, `LMSTUDIO_MAX_TOKENS`, `OPENAI_LOCAL_MAX_TOKENS`. Output budgets do not change context length or reasoning mode. Keep input plus output within the loaded context; higher limits do not guarantee completion. No automatic retry or partial-result save was added.

Validation: 174 unit tests, Ruff, JavaScript syntax and mocked settings/i18n/diagnostics browser checks passed. No real large-model generation, paid AI calls or video production were run. Back up private data and restart the application server after updating. The ZIP excludes private data and includes a separate checksum file.
