# v0.5.6-beta

## English

- Adds LTX 2.5 text-to-video and starting-image-to-video prompt profiles, based on official LTX documentation reviewed on 2026-10-18.
- Converts approved shots into chronological prose, with camera transitions, audio continuity and original dialogue in quotation marks. H3/Seedance formatting remains unchanged.
- Supports per-clip copy and TXT/JSON export. LTX start images are connected separately in the video workflow; this release does not analyze or transfer them.
- The current planner range remains 4–15 seconds. This is an application limit, not a claim about LTX's maximum generation length.
- Validation: 179 unit tests, Ruff, JavaScript syntax and browser conversion checks, including both LTX modes, clipboard contents, TXT export, UI language switching and existing model regressions. AI responses are mocked; actual video quality is not tested.
- No new runtime dependencies or API credential fields. Keys and local settings are excluded from release archives; local key storage remains plaintext.

## 한국어

- 컷과 카메라 전환, 소리의 연결을 시간 순서의 영어 문장으로 정리하고 대사는 인용부호 안에 원문 그대로 삽입합니다.
