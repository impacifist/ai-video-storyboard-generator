# v0.5.9-beta — Keep conversion shots aligned with the plan

## English

- Supplies an explicit per-clip shot ID contract, including repeated source IDs for continuation segments. JSON output schemas restrict clip and shot IDs to the selected plan. Conversion models may differ from storyboard-generation models.
- Restores a reordered list only when every clip and each clip's shot list has an exact, unique ID match. Whole direction objects move together; source timing, original dialogue and speaker assignments remain authoritative. The UI records this restoration without an extra AI request.
- Missing, duplicate, invented or misplaced IDs are never guessed or silently relabeled. Errors and the single automatic repair request now show the affected clip, expected/returned IDs, counts and missing/extra/duplicate entries. Real guide warnings and all other validations remain enforced.
- Existing source storyboards, saved conversions and node-compatible prompt formats are preserved. Reconvert to use the new instructions.

Validation: 212 unit tests, including synthetic 100-second/10-shot/three-person plans, long-shot continuations, selection gaps, all three video-model guides and all four AI adapters; Ruff, JavaScript syntax, browser conversion/save and three-language responsive checks. AI responses are mocked. The submitted input settings alone do not establish the cause of a particular failed AI response; no live AI or video-quality claim is made.

Restart the app after updating, then refresh with Ctrl+F5. Release ZIPs exclude private settings, API keys, databases and generated media.
