# v0.5.8-beta — Review shot-count differences

## English

- When a complete, valid storyboard has a different shot count, show the requested and generated counts, total duration and a preview instead of discarding the result.
- Choose **Use this draft** to accept and save without another AI request, or **Generate again** to retry the original request. A failed retry retains the previous draft. Draft JSON can also be downloaded.
- Acceptance updates the shot-count setting and records the choice. Existing saved storyboards remain unchanged until acceptance. Unaccepted drafts live in the current page session: use or download them before refreshing.
- Only count differences in otherwise valid, complete results with 3–60 shots are recoverable. Incomplete batches, invalid fields and missing locked shots remain errors.

Validation: 203 unit tests, Ruff, JavaScript syntax and browser checks for generation choices, conversion, three languages and responsive layouts. AI responses are mocked; no paid AI or video generation was run. Release archives exclude private settings, API keys, databases and generated media.

Stop the app, update its files, restart with `start.bat`, then refresh with Ctrl+F5. Back up private settings and storage locally before replacing an installation.

## 한국어

컷 수가 다르더라도 완전하고 유효한 결과라면 요청·생성 컷 수와 총 길이, 미리보기를 표시합니다. **이 결과 사용**은 추가 AI 호출 없이 저장하고, **다시 생성**은 원래 요청으로 재시도합니다. 재시도가 실패해도 앞선 초안은 유지됩니다. JSON으로 다운로드할 수도 있습니다.

미선택 초안은 새로고침 전에 사용하거나 다운로드하세요. 불완전한 생성, 잘못된 데이터, 고정 컷 누락은 계속 차단합니다. 유효한 3–60컷 결과만 수락할 수 있습니다. 단위 테스트 203개와 브라우저 검증을 통과했습니다. 업데이트 후 서버를 재실행하고 Ctrl+F5로 새로고침하세요.

## 日本語

完全で有効な結果のカット数が依頼と異なる場合、依頼数・生成数・合計時間とプレビューを表示します。**この下書きを使う**で追加のAI呼び出しなしに保存し、**再生成**で元の依頼を再試行できます。再試行に失敗しても前の下書きは残ります。JSONのダウンロードも可能です。

未確定の下書きは再読み込み前に使用するかダウンロードしてください。不完全な生成、不正なデータ、固定カットの欠落は引き続きエラーになります。有効な3〜60カットのみ確定できます。単体テスト203件とブラウザー検証を通過しました。更新後はサーバーを再起動し、Ctrl+F5で再読み込みしてください。
