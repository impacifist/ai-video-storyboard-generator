# v0.5.2-beta — 로컬 LLM의 3분 응답 대기 제한 제거

2026-10-17 · AI Video Storyboard Generator

## 수정

LM Studio 등 로컬 모델이 응답을 만드는 동안 앱의 HTTP 소켓 타임아웃(180초)에 걸려 요청이 끊길 수 있었습니다. `localhost`, `127.0.0.1`, IPv6 `::1`로 연결하는 요청은 이제 `timeout=None`으로 전송합니다. 첫 응답 대기와 응답 읽기에 앱의 고정 시간 제한을 적용하지 않습니다.

LM Studio, 로컬 Ollama, 로컬 주소를 설정한 OpenAI 호환 연결에 공통 적용됩니다. 일반 JSON과 Chat Completions 스트리밍 모두 같은 전송 처리를 사용하므로 동일하게 적용됩니다. UI에서 별도 설정할 필요가 없습니다.

클라우드 API의 기존 180초 소켓 타임아웃, 응답 크기·JSON 구조·원문 보존 검증과 토큰 예산은 유지합니다. 자동 재시도를 추가하지 않았습니다. 로컬 서버 자체의 시간 제한, 중단, 메모리 부족이나 연결 해제까지 앱이 해제할 수는 없습니다. 서버가 끝내 응답하지 않으면 앱은 계속 기다립니다.

## 업데이트

기존 앱 서버를 종료하고 `storage/`, `.local-secrets/`, 선택적으로 사용하는 `.env`를 백업하세요. 새 ZIP을 별도 폴더에 압축 해제하고 개인 데이터를 복사한 뒤 `start.bat` 또는 `python server.py`로 실행하고 브라우저를 새로고침하세요. Python 3.12 이상이 필요합니다. 기존 콘티와 프롬프트를 다시 생성할 필요는 없습니다.

ZIP에는 릴리스 커밋의 소스·문서·예제·테스트만 포함하며 개인 설정·API 키·저장 콘티·업로드·진단 파일은 제외합니다. `SHA256SUMS.txt`를 함께 제공합니다.

## 검증

- 테스트 157개와 Ruff를 통과했습니다.
- LM Studio·Ollama·로컬 OpenAI 호환 어댑터, IPv6, 로컬 스트리밍에서 실제 HTTP opener에 `timeout=None`이 전달되는지 확인했습니다. 클라우드와 유사 도메인에는 기존 제한을 유지하는지도 검사했습니다.
- 지연 응답을 보내는 로컬 HTTP 서버로 프로세스의 짧은 기본 소켓 제한을 넘겨도 응답을 받는 통합 검사를 수행했습니다. 실제 3분 이상 대기나 대형 로컬 모델 생성은 재현하지 않았습니다.
- 유료 AI 호출·영상 생성은 하지 않았습니다.

## English

Local inference requests no longer use the application's fixed 180-second socket timeout. LM Studio, local Ollama and OpenAI-compatible endpoints on `localhost`, `127.0.0.1` or `::1` now use an unlimited socket wait, including connection/response reads and Chat Completions SSE. No new UI setting is required.

Cloud timeouts, response-size/schema validation and token budgets remain unchanged. No automatic retries were added. Server-side timeouts, disconnections or failures can still end a request; a local server that never responds will leave the app waiting.

Restart the application server after updating. Existing saved storyboards and prompts are unchanged. Validation: 157 tests and Ruff passed, including provider/IPv6/streaming timeout checks and a delayed local HTTP response test. A real multi-minute local-model generation was not run. Private data is excluded from the ZIP.
