# v0.4.0-beta — 배경 참조와 긴 콘티 제작

2026-10-16 · AI Video Storyboard Generator

## 주요 변경

- **배경 이미지 참조:** 변환 화면에 전용 업로드를 추가했습니다. 같은 장소의 전체 구조와 다른 각도를 등록하고 좌석·문·창문·통로·인물 위치를 설명할 수 있습니다. 캐릭터·배경 합계 9장, 장당 5MB 이하 PNG/JPEG/WebP를 지원합니다. 배경은 캐릭터 Subject와 구분하고 각 클립에 해당 장소의 구조를 유지하는 영어 지시문을 넣습니다. 저장·재불러오기·첨부 순서·TXT/JSON/ZIP 내보내기에 반영했습니다.
- **최대 60컷과 권장 컷 수:** 목표 길이 10~180초, 컷 수 3~60개를 지원합니다. 길이에 따른 권장 범위를 표시하며 사용자의 컷 수를 자동으로 바꾸지 않습니다.
- **긴 콘티 분할 생성:** 13컷 이상은 전체 이야기·컷별 길이를 먼저 설계하고 최대 6컷씩 상세화합니다. 직전 컷과 고정 컷의 맥락을 전달하며 고정 컷은 다시 생성하지 않습니다. 모든 묶음이 검증된 경우에만 완성본을 반환합니다. 중간 실패에 자동 재시도나 부분 완성본 저장은 하지 않습니다. 재개용 체크포인트는 제공하지 않습니다.
- **대화와 관계 중심의 구도:** 대사의 의도·듣는 사람의 반응·관계 변화에 따라 리액션, 오버숄더, 투샷, 옆얼굴, 손·소품 디테일, 여백·깊이를 선택하도록 지침을 보강했습니다. 고정 구도 안의 연기도 허용하며 기법의 종류나 횟수를 강제하지 않습니다. 변환은 승인된 구도와 연출을 보존합니다.
- **행동의 선행 조건:** 특정 장소에 한정하지 않고 공간·소지·지식·동기·시간·결과를 이어가도록 생성·재생성·검수·변환의 공통 지침을 추가했습니다. 변환에서 발견한 원본 문제는 수정 의견으로 남기며 임의로 사건을 바꾸지 않습니다.
- **긴 응답 처리:** SSE 전송 데이터 32MB와 실제 생성 내용 2MB를 구분해 이벤트 오버헤드 때문에 조기에 실패하지 않도록 했습니다. 일반 요청·JSON 가져오기·콘티 저장은 16MB까지 허용합니다. 이미지 업로드 제한은 유지합니다.
- **일본어 대사 교정 분할:** 긴 대사 목록을 최대 12행·약 5,000자 단위로 교정합니다. 모든 교정 응답이 유효할 때만 일괄 반영하고 실패 시 생성된 원문과 검수 경고를 유지합니다. 입력 원문 대사·고정 컷·화자는 보존합니다.

## 설치·업데이트

1. Python 3.12 이상을 설치하고 `ai-video-storyboard-generator-v0.4.0-beta.zip`을 새 폴더에 압축 해제합니다.
2. 기존 설치는 서버를 종료한 뒤 `storage/`, `.local-secrets/`, 선택적으로 사용하는 `.env`를 백업하고 새 폴더로 복사합니다. 동작을 확인할 때까지 이전 폴더와 백업을 보관하세요.
3. `start.bat` 또는 `python server.py`로 실행하고 http://127.0.0.1:8765 를 엽니다. 이미 열린 화면은 새로고침합니다.
4. 기존 콘티와 저장된 변환 결과는 자동으로 재작성하지 않습니다. 새 연출 지침은 새 생성·재생성에, 배경 참조는 새 변환에 적용됩니다.

ZIP에는 추적되는 소스·문서·예제·테스트만 포함합니다. 개인 API 키·로컬 설정·저장 콘티·업로드 이미지·진단 결과는 제외합니다. `SHA256SUMS.txt`로 ZIP 체크섬을 확인할 수 있습니다.

## 검증과 범위

- 단위 테스트 132개, Ruff, JavaScript 구문 검사와 브라우저 검사 5종(생성·설정·보관함·변환·다국어)이 통과했습니다.
- 최대 60컷의 분할 생성, 고정 컷 보존, 실패 시 중단, 배경 참조의 모델별 번호·저장·TXT/ZIP, 영어 지시문과 원문 대사 보존을 검사했습니다.
- 실제 유료 AI·영상 생성 서비스는 이번 릴리스 검증에서 호출하지 않았습니다. 모의 AI 검사는 구조와 앱의 흐름을 확인하며 실제 연출·대사·영상의 품질을 보장하지 않습니다.
- 긴 콘티와 분할 대사 교정은 여러 API 호출로 비용과 시간이 늘어납니다. 호출별 출력 예산은 16,000토큰으로 유지합니다.
- 변환 AI에는 참조 이미지의 설명과 메타데이터만 전달하며 이미지 자체를 시각 분석하지 않습니다. 영상 서비스에는 매 클립마다 ZIP의 첨부 순서대로 캐릭터·배경 이미지를 직접 넣어야 합니다.
- 이 앱은 텍스트 콘티와 프롬프트를 만듭니다. 영상 렌더링·자동 합치기·콘티 그림 생성은 포함하지 않습니다.

## English

This beta adds background references, 3–60 shots with duration-based suggestions, outline-first generation for storyboards with 13+ shots, and richer Japanese 2D composition and action-prerequisite guidance.

Long storyboards expand in batches of up to 6 shots, carrying prior-shot context and locked anchors. All batches must validate before the completed storyboard is returned. There is no automatic retry or resumable checkpoint. Japanese proofreading uses bounded batches and applies edits atomically. These features add API calls, time and cost.

Background assets share attachment order with character images, using `<Picture N>` for MiniMax H3 and `Image N` for Seedance. Conversion preserves matching-location geometry through English instructions; images are not visually analyzed. Attach the actual reference images to the video service for every clip.

Install Python 3.12+, extract the ZIP into a new folder, stop the old server, back up and copy your private `storage/`, `.local-secrets/` and optional `.env`, then run `start.bat` or `python server.py`. Existing documents and saved conversions are not rewritten.

Validation: 132 unit tests, Ruff, JavaScript syntax checks and all five mocked browser suites passed. No paid model or video-generation calls were made for this release. The archive excludes credentials, private projects, uploads and diagnostic artifacts. Automated checks do not establish production model quality.
