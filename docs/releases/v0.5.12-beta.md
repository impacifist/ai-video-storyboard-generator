# v0.5.12-beta — Inspect and edit LLM conversion input

## English

- Adds **Inspect / edit LLM input** before prompt conversion. See clip-local and original source intervals, assigned dialogue, action/visual context, the system prompt, user JSON and output schema. Previewing and validating edits makes no AI call.
- Add segment-specific direction or edit the system prompt, story-context prose and per-segment action/visual/camera descriptions. Changes apply only to this conversion. Clip/shot identities, timing, original dialogue/speakers, states and reference bindings remain protected. Changed source or conversion settings invalidate stale edits before any AI call.
- Makes the scope of split-shot actions explicit: an unedited split segment carries whole-shot context, not a command to execute every action immediately. This can help diagnose or constrain actions appearing too early, but is not proof of video-model compliance.
- New successful conversions save the actual logical requests and parsed JSON outputs, including bounded repair calls. Inspect/download them from the result metadata and compare them with the final validated direction object. API keys and authentication headers are excluded. Older conversions have no retroactive trace; failed conversions do not save a new result.

Read the [input inspection guide](../guides/request-inspection.md). Downloaded traces can contain your story and personas; keep private traces local. Applied edits remain in page memory and clear on refresh or changing the loaded storyboard.

Validation: 226 unit tests, Ruff and JavaScript checks; browser request/compile/history/download tests, stale-edit blocking and three-language responsive checks; existing conversion/export regressions. AI responses are mocked; no live model or generated-video quality claim is made. Release archives exclude API keys, private settings, saved databases and generated media.

Update the app, restart the server and refresh with Ctrl+F5. Reconvert to capture a new request trace.

## 한국어

변환 설정에 **LLM 전송 내용 확인·수정**을 추가했습니다. 클립별 원본 시간 범위·행동·대사를 확인하고 구간 지시, 시스템 프롬프트와 사용자 요청을 수정할 수 있습니다. 미리보기·수정 검증은 AI를 호출하지 않으며 이번 변환에만 적용됩니다. 원본 대사·화자·시간·ID·상태·레퍼런스 연결은 보호하고, 조건이 달라진 오래된 수정 요청은 전송 전에 차단합니다.

새 변환 결과에는 실제 논리 요청과 LLM의 JSON 응답 이력이 저장되어 비교·다운로드할 수 있습니다. API 키는 포함하지 않지만 이야기와 페르소나는 포함될 수 있습니다. 기존 결과에는 소급 기록이 없으므로 새 기록은 다시 변환해 확인하세요. 단위 테스트 226개와 브라우저 검증을 통과했습니다. 업데이트 후 서버를 재시작하고 Ctrl+F5로 새로고침하세요.

## 日本語

変換設定に**LLMへの入力を確認・編集**を追加しました。クリップごとの元の時間範囲・動作・セリフを確認し、区間の指示、システムプロンプト、ユーザー入力を編集できます。確認・検証ではAIを呼び出さず、変更は今回の変換だけに適用します。元のセリフ・話者・時間・ID・状態・参考画像の対応は保護され、条件変更後の古い編集は送信前に拒否します。

新しい変換結果には実際の論理入力とLLMのJSON応答を保存し、比較・ダウンロードできます。APIキーは含みませんが、物語や人物設定は含まれる場合があります。過去の結果には遡って記録しないため、新しい記録には再変換が必要です。単体テスト226件とブラウザー検証を通過しました。更新後はサーバーを再起動し、Ctrl+F5で再読み込みしてください。
