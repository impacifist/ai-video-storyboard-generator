# v0.5.3-beta — AI 요청 진단 로그와 LM Studio 출력 예산

2026-10-17 · AI Video Storyboard Generator

## 변경

- 상단 **진단 로그** 또는 오류 옆 **진단 로그 보기**에서 요청 상태·경과 시간·종료 사유·입력/출력/추론 토큰·요청 출력 한도·HTTP 상태·소켓 대기 제한을 확인합니다. 요청 처리 중에도 열 수 있습니다.
- **로그 복사**, **로그 TXT 저장**, **완료된 로그 지우기**를 제공합니다. 최근 200건을 현재 서버 세션 메모리에만 보관하며 재시작하면 초기화됩니다. 이전 오류를 소급 복구하지 않습니다. 서버가 보내지 않은 수치는 제공 안 됨으로 표시합니다.
- 요청·응답 본문, API 키, 서버 URL과 예외 문자열은 로그에 기록하지 않습니다. 알려진 API 키는 모델 ID에서도 가립니다. 진단 API에도 기존 Host/Origin 검사를 적용합니다.
- **API 설정 → LM Studio → 요청 출력 한도**에서 `max_tokens`를 256~131072로 설정하고 저장합니다. 기본값은 기존 16000이며 콘티 제작·검수·변환에 공통 적용됩니다. `.env` 또는 환경변수 `LMSTUDIO_MAX_TOKENS`도 지원합니다. 다른 제공자의 출력 한도는 변경하지 않습니다.
- `length` 종료와 추론이 출력 대부분을 소비한 경우를 구분해 오류 화면과 진단 화면에서 설명합니다. 추론도 출력 예산을 사용할 수 있습니다. 입력 토큰과 출력 한도의 합이 로드한 모델의 컨텍스트 안에 들어가도록 조절하고, 추론이 과도하면 모델의 추론 설정도 확인하세요.

출력 한도를 높여도 완성이나 품질을 보장하지 않습니다. 미확인 추론 제어 옵션·자동 재시도·부분 결과 저장을 추가하지 않았습니다. 요청 성공 로그는 전체 콘티의 검증 통과를 뜻하지 않습니다. 로컬 LLM의 고정 소켓 대기 제한 제거와 기존 응답 크기·JSON·콘티 검증을 유지합니다.

## 업데이트

기존 서버를 종료하고 개인 `storage/`, `.local-secrets/`, 선택 `.env`를 백업하세요. 새 ZIP을 별도 폴더에 풀고 개인 데이터를 복사한 뒤 `start.bat` 또는 `python server.py`로 실행하고 브라우저를 새로고침하세요. Python 3.12 이상이 필요합니다. 기존 콘티와 변환 결과는 재작성하지 않습니다.

ZIP에는 릴리스 커밋의 소스·문서·예제·테스트만 포함합니다. 개인 데이터·키·업로드·진단 결과는 제외하며 `SHA256SUMS.txt`를 제공합니다.

## English

This update adds session AI request diagnostics, copy/TXT export, a persistent LM Studio output-token budget (default 16000, range 256–131072), and clearer errors for truncated responses dominated by reasoning. Inspect status, elapsed time, finish reason, token usage when supplied, requested output limit, HTTP status and socket timeout, even while waiting for a response.

The latest 200 request records live only in server memory and disappear on restart. Request/response bodies, API keys, endpoint URLs and exception text are excluded. Missing usage is not estimated. A successful AI request does not imply that the complete storyboard passed validation.

The LM Studio limit applies to generation, review and conversion; other providers retain their existing limits. Keep input plus the output budget within the loaded context. Raising the limit does not guarantee completion; check the model's reasoning settings when reasoning consumes most output. No unsupported thinking parameters, automatic retries or partial-result saves were added.

Validation: 169 unit tests, Ruff, JavaScript syntax and mocked settings/diagnostics/i18n browser checks passed. No paid AI requests or real large-model/video generation were run. Restart the application server after updating; back up and retain your private data. Private data is excluded from the release ZIP.
