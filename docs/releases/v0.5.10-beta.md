# v0.5.10-beta — Translate only the instruction fields that failed validation

## English

- When a completed, structurally valid direction draft fails the English instruction policy, the existing single repair attempt can now translate just the affected instruction strings. It does not ask the model to regenerate the storyboard or the entire direction object.
- Covers delivery instructions, camera/action prose and other renderer-owned English slots. Source dialogue, IDs, lookup keys, valid fields, warnings and approved clip structure remain untouched. Every returned translation must have the exact key, be nonempty where required and pass the English policy before it is applied atomically. The full result is then validated again.
- Adds a clearer delivery-field schema hint and removes ambiguity between preserving vocal intent and copying source-language delivery instructions. The UI shows how many instruction fields were translated.
- The initial request plus at most one repair remains the limit. Targeted translation handles up to 100 affected strings; other validation problems and larger batches retain the existing full-object repair path. Failed, malformed, empty or still non-English translations never save a partial result. Original speech remains in its original language; the English instruction check is not relaxed.

Validation: 220 unit tests, including all four AI adapters and H3/Seedance/LTX guides, malformed translation responses, preserved dialogue/IDs/warnings, failed-save protection and combined order restoration; Ruff, JavaScript syntax, browser translation/save and three-language responsive checks. AI responses are mocked. This reproduces the reported delivery-language failure without claiming a live Gemma model test or verified video quality.

Restart the server after updating, then refresh with Ctrl+F5. Release ZIPs exclude API keys, private settings, databases and generated media.

## 한국어

연기 지시 등 영어로 변환되지 않은 문구 때문에 검증이 실패하면, 전체 콘티를 다시 출력시키는 대신 문제가 된 지시문만 부분 번역하도록 개선했습니다. 원본 대사·컷 구성·화자 연결·정상 필드·경고는 유지합니다. 번역 결과는 한 번에 반영하고 전체 결과를 다시 검증하며, 비어 있거나 잘못된 번역은 저장하지 않습니다.

자동 교정은 기존처럼 최대 1회입니다. 부분 번역은 최대 100개 문구에 적용하며, 다른 검증 문제는 기존 교정 절차를 사용합니다. 단위 테스트 220개와 브라우저 검증을 통과했습니다. 실제 젬마 모델 실행은 포함하지 않은 모의 AI 테스트입니다. 업데이트 후 서버를 재시작하고 Ctrl+F5로 새로고침하세요.

## 日本語

演技指示などが英語になっていない場合、全体を再生成する代わりに問題の指示文だけを翻訳します。元のセリフ、カット構成、話者の対応、正常なフィールドと警告は維持します。翻訳をまとめて反映した後、全体を再検証し、空欄や不正な翻訳は保存しません。

自動修正は従来どおり最大1回です。部分翻訳は最大100件に対応し、ほかの検証エラーには従来の修正処理を使います。単体テスト220件とブラウザー検証を通過しました。実際のGemmaモデルの実行を含まない模擬AIテストです。更新後はサーバーを再起動し、Ctrl+F5で再読み込みしてください。
