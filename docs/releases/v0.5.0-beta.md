# v0.5.0-beta — 클립 길이 조정과 장면 연결 개선

2026-10-17 · AI Video Storyboard Generator

## 주요 변경

- **간단한 클립 길이 조정:** 변환 화면의 기본 흐름을 자동 추천 → 클립별 초 수정 → 변환으로 정리했습니다. 컷 끝과 장면 경계를 고려해 분할하고 짧은 꼬리 클립을 줄입니다. 공식 프로필은 설정한 상한 내 정수 4~15초를 지원합니다. 예를 들어 추천된 3개 클립을 각각 13초로 조정할 수 있습니다. 기존 분할 방식은 고급 옵션에서 선택합니다.
- **클립 내부 시간 배분:** 자동 추천 모드에서는 대사의 예상 길이와 AI가 제안한 연기 비중으로 컷별 시간을 재배분합니다. 지정한 클립 길이·개수, 원본 콘티와 대사는 유지합니다. 변환 후 계획 화면에도 최종 배분을 표시합니다. 시간 부족은 검토 메모로 남기며 속독이나 임의의 클립 연장으로 해결하지 않습니다.
- **경계에서 이어지는 연출:** 같은 컷의 연속, 승인된 컷 전환, 장면 전환을 구분하고 인접 클립 양쪽에 같은 행동·소리 연결 설명을 삽입합니다. 대사마다 앞선 행동이나 반응에 연결된 영어 발화 계기를 추가합니다. 분할 컷의 대사는 순서를 지키며 들어갈 수 있는 앞 구간부터 문장 단위로 배치합니다. 중간 클립에 추가되는 마무리·대기·재시작을 억제하고 원본의 의도된 침묵은 보존하도록 지침을 보강했습니다.
- **LM Studio 지원:** 별도 제공자 설정으로 로컬 OpenAI 호환 서버를 연결합니다. 기본 주소는 `http://127.0.0.1:1234/v1`이며 모델 ID, JSON 출력 방식, 선택적 API 키를 설정할 수 있습니다. OpenAI 키와 분리하고 로컬 주소만 허용합니다.
- **권장 컷 수 안내:** 권장 범위는 참고이며 필수가 아니라는 설명을 한국어·영어·일본어로 추가했습니다.
- **일반 API 안내:** 특정 개인 서비스의 이름·주소·연결 안내를 제거했습니다. OpenAI 호환 연결은 유지하며 Chat Completions SSE는 `.env`의 `OPENAI_CHAT_STREAM=true`로 명시적으로 선택합니다. 기본값은 비활성입니다.

## 설치·업데이트

1. Python 3.12 이상을 설치하고 `ai-video-storyboard-generator-v0.5.0-beta.zip`을 새 폴더에 압축 해제합니다.
2. 기존 서버를 종료하고 `storage/`, `.local-secrets/`, 선택적으로 사용하는 `.env`를 백업한 뒤 새 폴더에 복사합니다. 동작 확인 전까지 이전 설치와 백업을 보관하세요.
3. `start.bat` 또는 `python server.py`로 실행하고 http://127.0.0.1:8765 를 엽니다. 이미 열린 화면은 새로고침합니다.
4. 기존 콘티와 저장된 프롬프트는 자동 변경하지 않습니다. 새 연결 지침을 적용하려면 콘티를 다시 변환하세요. SSE를 사용하던 호환 서비스는 위 환경 설정을 추가해야 합니다.

ZIP은 릴리스 커밋의 소스·문서·예제·테스트만 포함합니다. 개인 API 키·로컬 설정·저장 콘티·업로드·진단 파일은 제외합니다. `SHA256SUMS.txt`로 체크섬을 확인할 수 있습니다.

## 검증과 범위

- 단위 테스트 153개, Ruff, JavaScript 구문 검사, 브라우저 검사 5종(생성·설정·보관함·변환·다국어)이 통과했습니다.
- 13초 × 3개 길이 유지, 원본·대사 보존, 연결 설명의 양쪽 삽입, 실제 장면 전환·선택 공백 구분, LM Studio 설정 격리·주소 검증·모의 연결을 검사했습니다.
- 실제 유료 모델과 영상 생성 서비스는 호출하지 않았습니다. 발화 시간은 글자 수 기반 추정이며 실제 음성을 측정하지 않습니다. 자동 검증은 실제 영상의 자연스러운 연결이나 연기 품질을 보장하지 않습니다.
- ComfyUI 워크플로우, 모션 문맥 프레임과 트리밍은 변경하지 않습니다. 생성된 영상의 실제 길이는 사용하는 외부 워크플로우에 따라 달라질 수 있습니다.
- 프롬프트 지시문은 영어로 출력하고 승인된 대사 원문은 유지합니다. 영상 렌더링·자동 합치기는 포함하지 않습니다.

## English

This beta adds a simple **Suggest clip lengths → edit seconds → convert** flow, conversion-only pacing refinement, paired visual/audio handoffs, per-line speech-onset cues, and local LM Studio support. Official profiles accept whole-second clip budgets within the configured limit, from 4 to 15 seconds.

Automatic mode refines shot allocations while preserving user-selected clip lengths and count, source storyboards and original dialogue. Timing estimates are heuristic, not measured speech. Intermediate clips are guided to continue the performance without an added ending or restart; authored silence and scene changes remain valid.

LM Studio has separate local-server settings and an optional API key. Generic OpenAI-compatible Chat Completions streaming is opt-in through `OPENAI_CHAT_STREAM=true` in `.env`; the default is disabled.

Back up private data, extract into a new folder, copy `storage/`, `.local-secrets/` and optional `.env`, then restart the server. Reconvert existing storyboards to apply the new prompt guidance. Existing saved results are not rewritten.

Validation: 153 unit tests, Ruff, JavaScript syntax checks and all five mocked browser suites passed. No paid AI or video-generation calls were made. Actual animation continuity remains unverified. ComfyUI workflows, motion-context frames and trimming are unchanged. The ZIP excludes credentials and private artifacts.
