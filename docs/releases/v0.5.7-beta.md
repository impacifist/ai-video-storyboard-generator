# v0.5.7-beta — Speaker binding and grouped references

## English

- Binds dialogue cues to the original speaker across MiniMax H3, Seedance and LTX. H3 reference speech explicitly connects `<Subject N> (Sx)`; other models retain their own syntax. Off-screen speech and approved voiceover are distinguished from visible speech. Original words and line order remain unchanged.
- Adds Character, Background, Prop and Other reference types in H3/Seedance reference mode. Group multiple images of one target, select its shots, and optionally associate a prop with a character. Other requires a reference purpose. Approved actions, prop holders and transfers remain authoritative.
- Simplifies reference entry with appearance defaults, optional notes and collapsible target groups. Supports English, Korean and Japanese.
- Validation: 193 unit tests, Ruff, JavaScript syntax, browser conversion/export/reference checks and three-language responsive checks. AI responses are mocked; actual generated video quality is not verified.
- Existing saved conversions and source storyboards are preserved. Convert again to use the new prompt assembly. Images must still be attached separately to the video workflow. LTX retains its starting-image mode, not this multi-image reference bundle.

Update into a separate folder after backing up private storage/settings. Keep backups local. Release ZIPs exclude API keys, local settings, databases and generated artifacts.
