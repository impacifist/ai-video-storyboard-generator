# v0.5.1-beta — 클립 분할 조작과 가이드 표시 개선

2026-10-17 · AI Video Storyboard Generator

## 변경 사항

- 고급 분할 설정을 접힌 영역에서 꺼내 분할 방식과 최대 길이를 항상 표시합니다.
- **클립 분할 적용** 버튼으로 선택한 방식·최대 길이에 따른 분할 계획을 만듭니다. 이 작업은 AI를 호출하지 않습니다.
- **클립 길이 자동 추천** 버튼은 자동 추천 방식으로 전환해 계획합니다. 프롬프트 변환 버튼의 위치와 기능은 유지합니다.
- 반복되던 **공식 원문** 링크를 텍스트 프롬프트 가이드·이미지 참조 가이드·샷 구성 규격 등 문서별 제목으로 구분했습니다. 적용 가이드와 시스템 프롬프트에도 제목을 붙였습니다.
- 새 문구를 영어·한국어·일본어로 제공합니다.

## 업데이트

Python 3.12 이상이 필요합니다. 기존 서버를 종료하고 `storage/`, `.local-secrets/`, 선택적으로 사용하는 `.env`를 백업한 뒤 새 ZIP을 별도 폴더에 압축 해제하고 개인 데이터를 복사하세요. `start.bat` 또는 `python server.py`로 실행한 뒤 브라우저를 새로고침하세요. 기존 콘티와 저장된 프롬프트는 변경하지 않습니다.

ZIP은 릴리스 커밋의 소스·문서·예제·테스트만 포함합니다. 개인 설정·저장 데이터·업로드·진단 파일은 제외합니다. `SHA256SUMS.txt`를 함께 제공합니다.

## 검증

단위 테스트 153개, Ruff, JavaScript 구문 검사, 변환·다국어 브라우저 검사를 통과했습니다. 선택한 방식으로 분할 적용, 자동 추천 전환, 문서별 링크 제목과 기존 변환 흐름을 모의 AI로 검증했습니다. 실제 유료 AI·영상 생성 서비스는 호출하지 않았습니다.

## English

Split mode and maximum clip length are now always visible. **Apply clip split** creates a plan using the selected settings without an AI call. **Suggest clip lengths** explicitly switches to automatic planning. The video-prompt conversion action is unchanged.

Official references now have distinct document titles, with separate headings for the applied guide and system prompt. New UI copy supports English, Korean and Japanese.

Stop the server, back up private data, extract into a new folder, copy `storage/`, `.local-secrets/` and optional `.env`, restart and refresh the browser. Saved storyboards and prompts are unchanged.

Validation: 153 unit tests, Ruff, JavaScript syntax checks and mocked conversion/i18n browser checks passed. No paid AI or video-generation calls were made. The ZIP excludes private settings and artifacts.
