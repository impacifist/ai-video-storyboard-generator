# v0.5.11-beta — Remove noisy adjacent-state warnings

## English

Removed the automatic review warning triggered solely by differences between a shot's end-state description and the next shot's start-state description. This applies to character and prop descriptions. The obsolete English/Japanese translation entry was also removed.

Source state data, editing, prompt compilation, timing checks and structural validation remain available. Existing storyboards do not need to be regenerated; opening or reviewing them again uses the updated review logic. Previously exported files are not rewritten.

Validation: 220 unit tests, Ruff, JavaScript syntax, browser editing/review/import/export checks and English/Korean/Japanese responsive checks. No live AI or video generation was run. Release archives exclude private settings, API keys, databases and generated media.

Restart the server after updating and refresh with Ctrl+F5.

단위 테스트 220개와 브라우저 검증을 통과했습니다. 업데이트 후 서버를 재시작하고 Ctrl+F5로 새로고침하세요.
